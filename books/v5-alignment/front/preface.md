# 前言

这一卷讲的是模型“会说话”之后的事。

前三卷把模型造出来了：它读过几万亿个 token，学会了预测下一个词，也学会了按 Transformer 的方式把上下文揉在一起。但它还不会听人话。你让它总结，它给你续写；你让它道歉，它接着把道歉的话往下写；你问它一个不该答的问题，它照样兴高采烈地答完。这不是能力不够，是训练目标的问题：预训练只教它“文本长什么样”，没教它“该做什么”。

把这两件事接起来的过程叫对齐。这一卷按时间顺序讲它：

- 先用几千到几十万条示范，教它“按格式回答”，这是 SFT；
- 再用人类（或强模型）的偏好，教它“哪个回答更好”，这是 RLHF 与 DPO；
- 然后用可自动验证的奖励，教它“算对、跑通、答中”，这是 RLVR 与推理模型；
- 最后把同样的思路搬到多步任务上，教它“用工具把事情做完”，这是 Agent 后训练。

每一章都按同一个路子写：先说这一步要解决什么失效，再给方法，再算代价，最后说它在哪里露馅。对齐这件事的难点从来不在算法，而在于“好”这个目标写不进损失函数，只能用一个代理去逼近，而任何代理都会被优化过程钻空子。整卷反复出现的主题就是这个：代理目标、分布偏移、和它们带来的假进步。

读完这一卷，你应该能判断三件事：一个模型的行为是训练出来的还是提示出来的；一个“效果提升”是真提升还是奖励作弊；以及在多步任务上，什么时候该训练、什么时候该改环境。

这一卷不要求你会推导强化学习。策略梯度、重要性采样这些概念会在用到的地方现场解释，公式只保留能帮你判断“哪里会坏”的部分。它假设你读过第二卷（Transformer 的结构）和第三卷（预训练与数据），但不需要读过第四卷。

书里的例子尽量用公开的实验和公开的模型配置，凡是推断的地方都会说明是推断。数字给量级，不追求精确到小数点后两位。
