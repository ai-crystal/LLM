## 画图与做视频

一家做小家电的公司要上新品，市场部用生成模型做海报。

第一轮出了二十张，构图漂亮的不少，能用的只有三张。问题很集中：有两张把产品上的 logo 拧成了错字，有一张把三孔插座画成了两孔，还有一张画面里出现了六根手指。

改到第三轮，他们摸清了脾气：让它画氛围、光影、场景，很稳；让它画准确的文字、准确的接口、准确的数量，基本别指望。最后的流程变成两边分工：模型出背景和氛围，产品和文字用设计软件贴上去。

这一章讲这类模型：它怎么画出图，为什么画得好又错得离谱，以及用了之后会在版权上踩什么坑。

### 从噪声里长出图

画图的模型和写字的模型，机制上不是一回事。

写字是自回归：一个 token 一个 token 往后接。画图的主流做法叫扩散：从一张纯噪声的图开始，一步一步去噪，每一步去掉一点点，几十步之后剩下的就是一张图。

训练时的做法正好相反：拿一张真图，按随机的强度加噪声，让模型学会“看到这个程度的噪声，应该把噪声去掉多少”。它做的就是这件事，重复几百万次。学会之后，从纯噪声出发，反复应用它学到的“去噪”规则，就能一步步逼近一张像样的图。

文字提示怎么控制它？训练时，每张图都配一段描述，模型学到的是“在这种描述下，噪声该往哪个方向去”。于是你写“雨夜的霓虹街道”，它就往那个方向去噪。

还有另一条技术路线，是把图像也切成 token，然后用写字的办法一个 token 一个 token 地“画”出来。它的好处是能和语言模型用同一套架构，图文混排的训练也更容易；坏处是图像 token 数量大，逐个生成很慢，而且细节的连续性不如去噪。两条路线这几年在互相借鉴：扩散模型开始借用语言模型的结构，自回归模型开始用更高效的图像编码。对使用者来说，这个区别通常不体现在界面上，只体现在速度、细节和文字渲染能力上。

这个过程和“从素材库里拼”完全不同。素材库里没有你这张图，它是从噪声里一步步算出来的。这一点在讨论版权时会变得很重要。

### 提示词在这类模型里长什么样

写字的提示和画图的提示，写法不一样。

写字讲究把要求说清楚：任务、约束、格式。画图讲究把画面说具体：主体是什么、在做什么、在什么环境、什么光线、什么镜头、什么风格、什么画幅。

一个能用的结构大概是这样：主体（一只橘猫）＋动作（趴在窗台上）＋环境（雨天的旧公寓）＋光线（侧逆光，暖色）＋镜头（中景，浅景深）＋风格（胶片质感）＋画幅（竖版三比四）。

为什么要这么啰嗦？因为模型对名词和形容词最敏感。你写“温馨”，它不知道你要什么；你写“暖黄的台灯、木质桌面、冒着热气的杯子”，它就有东西可抓。形容词给方向，名词给材料。

还有一种写法叫负向提示：告诉它不要什么。不要文字、不要多余的手指、不要水印、不要过曝。这在一些模型上很有效，因为它是从“往哪个方向去噪”里排除掉一部分方向。

可复现也是实际问题。同一个提示，两次生成的图不一样，因为起始噪声是随机的。想复现，就得固定随机种子；想微调，就固定种子改一个词，看变化。这是工作流里的基本功。

看一个实际改动。原来写“一个温馨的早餐场景”，出来的是煎蛋、咖啡、窗边，全是套话。改成“木质桌面上，一只白瓷碗装着燕麦，旁边半杯黑咖啡，窗外的光斜进来，在桌面拉出一条长影子，浅景深”，六张里五张能用。

改动的本质是把形容词换成了可画的名词和关系。它没有“温馨”这个概念，只有“这类画面常见的元素组合”。你给元素，它就组合；你给判断，它只能猜。

### 它学的不是几何，是像

理解这类模型的局限，关键在一句话：它学的是“图像看起来是什么样”，不是“场景在物理上如何成立”。

这解释了几类固定的错误。

文字写不对。图里的招牌、标签、书脊上的字，经常是“看起来像字母的笔画组合”。因为文字在这个模型眼里不是符号，是纹理。有些新模型专门加了文字渲染能力，好一些，但仍然不建议让它画需要精确拼写的字。

手和手指容易错。手在训练图里姿态极多、遮挡极多，而且五是五、六是六这种计数对它是难的。它画出的是“像手的形状”，指头数目常常由局部纹理决定，不由整体结构决定。

数量不可控。“画三只猫”可能出来四只。它没有计数的机制，只有“猫多一点的画面”这个方向。

物理会崩。倒水的水流不从壶嘴出、镜子里的人不对应、两只手拿着同一根绳子。这些在单张图里不明显，稍微一看就露。

精确尺寸做不到。你要一个 800 乘 200 像素、左边留白三分之一的横幅，它能给构图接近的，但比例、留白、元素位置都要后期调。

这些错误的共同点是：它们都属于“结构性、可验证”的东西，而模型擅长的是“氛围、风格、质感”，恰恰是不可验证的那部分。

| 操作 | 可靠度 | 说明 |
|---|---|---|
| 局部重绘 | 高 | 有原图约束，只改一块 |
| 扩图 | 高 | 背景和材质接得上 |
| 去物 | 高 | 复杂纹理也能补 |
| 换风格 | 中 | 主体会跟着变一点 |
| 一句话生成 | 低 | 全靠猜，要多次重试 |

### 一致性是最难的一关

真正做商业项目时，最麻烦的不是画得好看，是画得一致。

同一个角色，换一个姿势、换一个场景，脸就变了。同一个产品，换一个角度，细节就对不上。同一套视觉体系，做十张图，风格漂移。

原因是每一次生成都是独立的，模型不记得上一张图长什么样。业内的解法是“给参考图”：把已有的形象作为条件输入，让它在这个基础上变化；或者训练一个专属的小模型，把这个形象“记”下来。

后者的做法值得多说一句。拿二三十张同一个角色的图，在一个通用模型上做一次轻量微调，就能得到一个“只认这个角色”的小模型，文件往往只有几十到几百 MB。它生成任何场景时都能保持这张脸、这身衣服。这套做法在漫画、游戏、电商里已经很常见，成本是一天的工作量加一点算力。它的局限是：只认一个角色，换角色要重训。

所以真实的商业流程通常是：先定一套视觉资产（角色设定图、产品多角度图、色板），再用这些资产去约束每一次生成，最后人工修。模型负责“快速产出大量候选”，人负责“挑和修”。把模型当成的美工，会失望；把它当成出图很快的实习生，就顺手了。

### 编辑往往比生成更有用

商业项目里，用得最多的其实不是“从无到有生成”，是“改一张已有的图”。

局部重绘：圈出一块区域，只改这一块。换掉背景里的路人，把桌上的杯子换个颜色，给模特换一件外套。其余部分保持不变，这比重新生成一张再对齐要省事得多。

扩图：图不够宽，往外补。补出来的部分要和原图的光线、透视、纹理接上，这件事模型做得相当好，尤其是背景和材质。

去物：把画面里不想要的东西擦掉，用周围的内容填上。这比传统的修补工具自然得多，尤其是复杂纹理（草地、人群、砖墙）。

换风格：保留构图和主体，把整体质感换掉。这在做系列物料时很有用：同一张构图，出五套风格给客户挑。

这些操作的共同点是：有原图作为强约束，模型的自由度小，出错的空间也小。所以它们的可靠性明显高于“一句话生成”。真实的生产流程里，常常是先生成一张大致对的底图，再用编辑一步步修到能用。

### 视频：多出来的一维

视频生成是把上面这套搬到时间轴上，难度立刻上一个台阶。

第一个问题是时长。图像的去噪是几十步，视频要在每一帧上做，还要保证帧与帧之间连贯。一分钟的视频，按每秒二十四帧算是一千四百多帧，计算量是单张图的千倍量级。

第二个问题是一致性。不只是角色一致，还有光照一致、物体不凭空出现、背景不忽然变形。这些东西在图像里看不出，在视频里一眼就露。所以视频模型要有“时间上的记忆”，让它在生成第 100 帧时还知道第 1 帧发生了什么。

第三个问题是物理。人走路的步态、水流的走向、布料的下垂，这些在图像里可以糊过去，在视频里必须连续成立。目前的效果是：短镜头、慢动作、简单场景很好；长镜头、快速运动、多物体交互容易崩。

第四个问题是控制。做视频的人要的不只是“生成一段”，还要“这个镜头往左推”“这个人物走到这里停”“这段接上一段”。这些控制在图像上已经比较成熟（构图、姿态、深度），在视频上还在补。

把计算量算一遍，就知道为什么贵。一张 1024 的图，去噪二十步，每步在这类硬件上约半秒，十秒出一张。一分钟视频按每秒二十四帧是一千四百四十帧，一帧十秒，单卡要跑四个小时。就算把帧率和分辨率都压下来，也是几百倍的差距。

所以现在的定价方式是按秒。公开的价格量级大致是每秒几毛到几块，一条五秒的镜头两三块，重试三次就是七八块。一条六十秒的片子拆成十二个镜头，平均每个重试三次，光生成就两百多块，还没算配音和剪辑。这个成本对个人创作者是可接受的，对一天要出十条片子的团队就不轻。

所以视频生成现在的定位，更接近“素材生成”：出几个可用的短镜头，剪进片子；而不是“一句话生成一支广告片”。

### 真正做一条视频，中间还有好几步

“生成一段视频”听起来是一步，实际落地时至少五步，每一步都有它自己的坑。

**先分镜。** 把想说的话拆成一组镜头：景别（近景还是全景）、主体动作、时长、转场。这一步目前还是人做高效，因为它靠的是叙事，不是画质。镜头表定下来，后面每一步都有验收标准。

**再出关键帧。** 每个镜头先生成一张图，确认构图、光影、人物长相。这一步便宜且好改。直接上视频的问题是一旦不对，要整段重做，而重做一次的成本是出图的几十倍。

**然后图生视频。** 从关键帧出发让画面动起来。经验值是单镜头三到五秒最稳，再长就开始出现“人脸慢慢变样”“背景莫名拉长”。想拍一分钟的片子，正确做法是切成十几个三秒镜头分开生成，而不是让它一次吐一分钟。

**配音与口型。** 一旦画面里有人说话，顺序很关键：先有声音（配音或真人录音），再让口型去对声音。反过来先有画面再配音，嘴型基本对不上，观众一眼就看出是后期贴的。

**最后是音效与字幕。** 字幕要避开画面主体，音乐和音效的版权往往比画面更容易出问题。

如果任务不是“生成”而是“看懂已有视频”，难点换成抽帧。一分钟视频按每秒 24 帧是一千四百多帧，全送进去不现实；常见的做法是先用每秒一帧粗看全片，找到相关的那几十秒，再对那一段加密到每秒五帧。固定间隔抽帧最省事，但长镜头里的动作会被跳过；按镜头切点抽帧更聪明，但对一镜到底的素材无效。

### 版权：三种不同的风险

用生成模型做图，版权上有三种风险，性质完全不同。

第一种是训练数据的争议。模型是用大量图片训练出来的，这些图片大多有版权。这场争论和文本那边一样，各国判法不同，还没有统一规则。这一层的风险主要落在模型提供方身上，使用者一般不受直接追责，但如果某个模型因此被下架，你的工作流会中断。

第二种是输出与原作实质相似。这是使用者最直接的风险。你让它“画一个像某位在世插画师风格的封面”，出来的图如果构图、配色、标志性元素都和某张具体作品接近，对方可以主张侵权。风格本身在很多司法辖区不受版权保护，但“具体表达”受保护，而这两者的界线由法官画，不由你画。

第三种是商标与肖像。生成一张海报，画面里出现了可识别的品牌标志、真实人物的脸、受保护的卡通形象，这些都不是“风格”问题，是明确的权利问题。商用之前必须清。

可执行的做法有几条。把“模仿某位在世创作者”从提示规范里去掉，改成描述视觉要素：配色、构图、材质、光线。生成流程里加一道人工确认，确认画面里没有可识别的角色、商标、他人作品的标志性元素。保留每次生成的提示词和模型版本记录，万一有争议，你能证明这是独立创作。对外发布的内容，按平台要求标注“AI 生成”。

这些做法不解决法律问题，但它们把“明显会输的案子”挡在了发布之前。

### 一个正在成形的分工

把这一章的东西收一下，生成模型在图像和视频上的位置，大致是这样一个分工。

它擅长：快速给出大量风格化候选、把抽象描述变成具体画面、做那些“想不出来长什么样”的探索、批量生成素材、修图和扩图这类编辑操作。

它不擅长：精确的文字、精确的数量、精确的尺寸、跨图的一致性、需要物理正确的场景、以及需要承担法律责任的画面。

所以真实的工作流是“生成 + 挑选 + 人工修 + 合规检查”，四步都不能省。省掉哪一步，问题就从哪一步冒出来。

### 四个常见的误解

第一个误解是“提示词越长越专业”。长提示的作用是把画面拆成可画的元素，不是堆形容词。堆十个“高级、精致、电影感”，不如写清“什么光、什么镜头、什么材质”。超过一定长度之后，模型还会开始丢前面的词。

第二个误解是“固定种子就能复现”。种子只固定了起点，模型版本一更新、采样器一换、后端精度一变，同一串参数出来的图就不一样。要长期复现，得把模型版本也锁住。

第三个误解是“生成出来的图就是我的，可以随便商用”。它不侵权的前提是画面里没有可识别的商标、肖像、他人作品的标志性元素。这三样在商用素材里出现得比想象中频繁，尤其是产品和人物。

第四个误解是“视频生成的难点是画质”。单帧画质早就不差了，难的是连贯和控制。一段五秒的镜头，人物脸慢慢变形、背景莫名拉长，这类问题比“不够清晰”更致命，也更难修。

::: {.keypoint}
**记住这三件事**

一、画图的主流做法是从噪声一步步去噪，它学的是“图像看起来像什么”，不是场景的几何与物理。

二、它擅长氛围和风格，不擅长文字、数量、尺寸、一致性；这些恰好是商业项目最较真的部分。

三、版权风险有三种：训练数据的争议、输出与原作实质相似、商标与肖像；能控的是后两种，靠规范和人工确认。
