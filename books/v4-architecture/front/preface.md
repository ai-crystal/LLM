# 前言

第二卷讲的是 2017 年的 Transformer。这一卷讲它之后被改成了什么样子，以及每一处改动是为了省什么。

读完这一卷，你应该能：

- 算出一个模型在给定上下文下的 KV 缓存大小，并解释它为什么是长上下文服务的瓶颈；
- 说清 MQA、GQA、MLA 各自压缩了什么，代价是什么；
- 解释 FlashAttention 为什么省显存却不省 FLOPs；
- 说清混合专家的路由、负载均衡和专家并行；
- 理解 Attention Residuals 为什么把残差连接改成深度方向的注意力；
- 面对一个具体场景，判断该选稠密还是稀疏、该用多长的上下文、该不该上混合架构。

这一卷的每一节都围绕同一张账本：显存、带宽、算力。结构没有优劣，只有交换。
