# 前言

模型训完之后，还有一件同样费钱的事：把它跑起来。

一件常被忽略的账：训练是一次性的，推理是每天都要付的。一个日活百万的应用，如果把每个 token 的成本从两厘压到一厘，省下的钱比重新训一次模型还多。反过来，一次训练时的小改动（多一层、宽一点、专家多一点），可能在推理侧变成十倍的代价。

这一册讲怎么在这笔账上做取舍。十章分三块：

前四章讲清一次生成到底在做什么，瓶颈在哪：两个阶段的差别，KV 缓存为什么会把显存吃满，批处理怎么把卡喂饱，前缀复用能省多少。这几章是后面所有优化的地基，数字都在这里面。

中间四章讲三种主要手段：量化（用更少的位存权重）、剪枝与蒸馏（用更小的模型代替）、投机解码（用便宜的模型猜、用贵的模型验证）。每一种都有它的收益曲线和失效场景，都不是"开了就快"。

最后两章讲系统：PD 分离与多机推理，以及容量规划。最后一章把前面所有东西串成一个完整的部署复盘，从 SLO 倒推到卡数。

这一册的数字很多，都是估算，给的是方法与量级。学会算法比拼记住数字有用：换一张卡、换一个模型，数字全变，但算式不变。

读书时建议手边放一份主流模型的配置（层数、隐藏维度、头数、专家数），每章算一遍，比读十遍有用。
